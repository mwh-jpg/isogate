# Roadmap

已完成能力与待接入项按里程碑列出。状态以代码和测试为准，不使用营销口径。

## 已完成（v0.1）

- [x] Go + Gin + PostgreSQL 16 + Redis 7 后端骨架
- [x] AES-256-GCM / argon2id / API Key SHA-256
- [x] SSRF Dial 阶段双重校验与独立 Transport 池
- [x] `/v1/messages` 非流式与 SSE 透传、usage 解析
- [x] Redis Lua 原子并发锁与 RPM 滑窗
- [x] 429/529 冷却、401/403 凭证异常，仅作用当前账号
- [x] OpenAI Chat Completions 兼容
- [x] 审计哈希链与公开校验接口
- [x] 免构建租户控制台（设计稿风格）
- [x] 付款后自动分配静态 IP 的数据模型与管理员手动占位入口
- [x] 静态 IP 资源池（批量录入 / SSRF 拦截 / 探测验健康 / 停用启用 / 从池分配 / 回收释放库存）
- [x] 一账号一 IP：账号创建时原子分配独立出口、删除回收释放库存、管理端按账号管理
- [x] 管理员后台（用户/套餐、账号与 IP、静态 IP 池、全局审计、审计链校验）

## 待接入（v0.2）

- [ ] 用户提供的静态 IP 获取接口：付款回调 → 自动获取 IP 入池 → 由 `CreateAccountWithProxyFromPool` / `AssignIPFromPoolForAccount` 分配给账号
- [ ] 支付渠道回调与套餐到期自动停服
- [ ] 真实上游成功 200 联调（需用户提供可用 API Key / Bedrock / Vertex 凭证）
- [ ] 邮件通知：IP 分配成功、代理不健康、套餐到期
- [ ] 管理后台批量操作与 IP 池余量告警

## 明确不做

- 不混用不同用户的上游账号与出口 IP；同一用户的不同上游账号也不共用出口 IP。
- 不提供共享账号池或账号租赁。
- 不承诺绕过上游风控；服务条款合规由用户自行负责。
